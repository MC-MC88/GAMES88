Cinq chiffres à deviner, cinq essais. Comme Wordle, mais pour les nombres.

👋 Welcome

Vous connaissez Wordle. Tout le monde connaît Wordle. Cinq lettres, six essais, des carrés verts et jaunes qui ont envahi vos fils d'actualité pendant une bonne partie de 2022. Et une fois qu'on a compris la mécanique, on a envie de la retrouver ailleurs — avec des chiffres, par exemple.

C'est exactement ce que fait NUMBRLE88. Une version numérique de ce principe simple : devinez un code à cinq chiffres en cinq essais, avec un retour visuel après chaque tentative. Vert si le chiffre est au bon endroit. Jaune s'il est dans le code mais ailleurs. Gris s'il n'y est pas du tout. Cinq lignes, cinq colonnes, un pavé numérique en dessous, et un petit tableau qui rappelle les trois couleurs.

Ce n'est pas une révolution. C'est la version numérique d'un jeu qu'on pourrait jouer sur un coin de nappe. Mais il est fait correctement, sans pubs, sans compte, sans "essai gratuit puis 4,99 € par mois". Un seul fichier HTML, cinq thèmes vintage, un pavé numérique, un clavier physique qui fonctionne aussi, et une modale à la fin qui vous dit si vous avez gagné et en combien d'essais.

Les cinq thèmes sont là pour ça aussi. Noir — le défaut — c'est du X-Files croisé avec Batman la série animée : gris anthracite, un seul accent jaune moutarde, Special Elite pour le titre comme une vieille machine à écrire. Campout — violet profond, orange vif, vert forêt, Bangers à la place de Special Elite, une ambiance de feu de camp dans les années 90. Grim — rouge sang sur noir profond, Billy & Mandy. Comic — crème et sépia, Rye à la place du titre, une couverture de comics doré. Wild — brun, ocre, feuille d'automne, un clin d'œil à Where the Wild Things Are.

Vous changez de thème en un clic, et tout se recolore : les tuiles, le clavier, les boutons, la modale, même la couleur du grain sur l'écran. Le jeu est le même dans tous les cas.

✨ Ce que vous trouverez

Cinq thèmes vintage, chacun une ambiance à part.
Les pastilles dans un bandeau arrondi en haut de l'écran basculent instantanément. Noir — gris anthracite, accent jaune moutarde, Special Elite monospace, une ambiance de dossier secret. Campout — violet profond, orange vif, vert forêt, Bangers pour le titre, comme une affiche de dessin animé des années 90. Grim — rouge vif sur noir, presque menaçant, blanc comme unique respiration. Comic — crème et sépia, Rye pour le titre, une couverture de livre d'images. Wild — brun, ocre, feuille morte, Where the Wild Things Are. Chaque thème change les polices, les couleurs des tuiles, du clavier, des boutons, et même la teinte du grain d'écran.

Cinq chiffres à deviner, cinq essais.
Le code secret est tiré au hasard au démarrage : cinq chiffres entre 0 et 9, dans un ordre aléatoire, avec répétitions possibles. Vous avez cinq tentatives pour le reconstituer. Chaque tentative est une ligne de cinq tuiles. Tant que vous n'avez pas validé, les tuiles restent vides — juste des cases à remplir.

Un pavé numérique pensé pour le pouce.
Deux rangées de cinq touches : 1 2 3 4 5 puis 6 7 8 9 0. Elles sont larges, hautes, avec une ombre portée sous chacune qui s'enfonce quand vous appuyez — comme un vrai clavier. Un clic ajoute un chiffre à la ligne en cours, à la prochaine position vide. Rien de plus compliqué.

Vert, jaune, gris — et une légende pour s'y retrouver.
Sous la grille, juste avant le clavier, un petit tableau rappelle les trois couleurs : Correct spot pour le vert, Wrong spot pour le jaune, Not in code pour le gris. C'est discret, mais ça évite d'avoir à se souvenir des règles si on revient après une pause.

Une animation de retournement.
Chaque tuile se retourne avec une rotation 3D de 0,4 seconde au moment où elle se colore — d'abord la première, puis la deuxième, la troisième, la quatrième, la cinquième, avec un décalage de 100 ms entre chaque. Ce n'est pas juste un changement de couleur, c'est un petit moment chorégraphié.

Un clavier physique qui fonctionne aussi.
Tapez 1, 2, 3, 4, 5 sur votre clavier d'ordinateur et ils apparaissent dans la grille. Appuyez sur Entrée pour valider, sur Backspace pour effacer. Tout fonctionne, comme si vous jouiez sur le pavé numérique — parce que c'est le même code qui s'exécute.

Un clavier visuel qui se souvient.
Quand vous validez un essai, les touches du clavier virtuel se colorent aussi. Un chiffre trouvé au bon endroit devient vert. Un chiffre trouvé au mauvais endroit devient jaune. Un chiffre qui n'est pas dans le code devient gris. Et les règles de priorité sont respectées : le vert l'emporte sur le jaune, le jaune sur le gris.

Un bouton Clear qui efface toute la ligne.
Un clic, et la ligne en cours se vide complètement. Utile si vous vous êtes trompé au milieu, ou si vous voulez juste recommencer votre tentative.

Un bouton Submit qui refuse les lignes incomplètes.
Si vous n'avez pas entré les cinq chiffres, appuyer sur Submit ne fait rien — sauf secouer la ligne horizontalement pendant 0,3 seconde, comme un petit "non" de la tête. Impossible de valider une ligne incomplète.

Un bouton New Game qui redistribue tout.
Un clic, et un nouveau code secret est tiré, la grille se vide, le clavier se réinitialise, la modale disparaît. Aucune confirmation, aucune limite — vous pouvez relancer autant de fois que vous voulez.

Une modale de fin, sobre.
Si vous trouvez le code, une modale apparaît avec VICTORY! en gros, le message "You cracked the code in X tries!", et le code révélé en grand dans la couleur verte. Si vous épuisez vos cinq essais, la modale affiche GAME OVER, "The secret number was:", et le code secret en rouge. Un bouton Play Again pour recommencer immédiatement.

Un grain de film sur tout l'écran.
Un filtre SVG de bruit à 10 % d'opacité donne à chaque thème une texture légèrement imprimée. Ça ne se voit presque pas, mais ça enlève le côté "écran plat" qui aurait rendu le tout un peu froid.

Une signature ASCII en pied de page.
Sous la ligne de copyright, un petit bloc de caractères dessine M C 8 8 en monospace. Discrète, toujours là.

Responsive, du téléphone à l'écran large.
La grille et le clavier se redimensionnent, les tuiles rétrécissent sur petit écran, la police du titre s'adapte. Tout est pensé d'abord pour un téléphone, et ça tient aussi très bien sur un écran large.

🧭 Comment ça marche

1. Ouvrez le fichier.
Un seul HTML, pas de build, pas d'installation. La grille apparaît vide, cinq lignes de cinq tuiles, avec le thème Noir par défaut. Le code secret a déjà été tiré au hasard.

2. Tapez un chiffre.
Utilisez le pavé numérique en bas de l'écran, ou votre clavier physique. Chaque chiffre se place dans la prochaine tuile vide de la ligne en cours. La tuile active est mise en surbrillance avec une bordure plus claire.

3. Effacez si besoin.
Le bouton Clear, ou la touche Backspace de votre clavier, effacent toute la ligne en cours. Pas de suppression chiffre par chiffre — c'est tout ou rien.

4. Validez.
Le bouton Submit, ou la touche Entrée. Si la ligne est incomplète, elle tremble et rien d'autre ne se passe. Sinon, les cinq tuiles se retournent une par une, avec un décalage, et se colorent en vert, jaune ou gris.

5. Lisez les couleurs.
Vert : le chiffre est dans le code, à cette position. Jaune : le chiffre est dans le code, mais pas à cette position. Gris : le chiffre n'est pas dans le code du tout. Les règles de comptage sont les mêmes que Wordle : si un chiffre apparaît deux fois dans votre essai mais une seule fois dans le code, seul le premier est coloré en vert ou jaune, l'autre passe en gris.

6. Devinez en cinq essais.
Vous avez cinq lignes. Si l'une d'elles est entièrement verte, vous avez gagné, et une modale apparaît après un court délai. Si vous remplissez les cinq lignes sans trouver, la modale vous révèle le code secret.

7. Changez de thème si l'envie vous prend.
Les cinq pastilles dans l'en-tête. Un clic, tout change instantanément. Votre choix n'est pas sauvegardé — à la réouverture, vous revenez à Noir.

8. Recommencez.
Le bouton New Game ou Play Again dans la modale. Un nouveau code secret, une grille vide, et vous repartez.

🛠️ Petits coups de main

"Le code peut-il contenir deux fois le même chiffre ?"
Oui. Le code est tiré chiffre par chiffre, indépendamment, donc 11223, 00000 ou 55555 sont tous des codes valides. Ça change la façon de raisonner : un chiffre peut être présent une, deux, ou trois fois dans le code, et il faut parfois deux essais pour comprendre combien de fois il apparaît.

"Comment sont gérées les répétitions dans le retour de couleur ?"
Exactement comme dans Wordle. Si le code contient un seul 3 mais que votre essai en contient deux, seul le premier 3 sera coloré (en vert ou jaune selon la position), et le second sera gris. Si le code contient trois 7 et que votre essai en contient deux, les deux seront colorés — mais vous ne saurez pas qu'il y en a un troisième, il faudra le déduire.

"Puis-je utiliser le clavier de mon ordinateur ?"
Oui. Les chiffres 0 à 9 fonctionnent, Entrée valide, Backspace efface. C'est exactement le même comportement que les boutons à l'écran, et le clavier virtuel se colore au fur et à mesure comme si vous aviez cliqué.

"Pourquoi le bouton Submit secoue la ligne quand elle est incomplète ?"
Parce qu'un clic silencieux, quand on vient de finir de taper, est ambigu — on ne sait pas si le bouton a reçu le clic ou pas. Une petite secousse horizontale de 300 millisecondes dit clairement : "il manque quelque chose, regarde bien". C'est une convention discrète, pas une sanction.

"Combien de temps dure une partie ?"
Entre trente secondes et deux minutes, selon la chance et la vitesse à laquelle vous déduisez les chiffres. Il n'y a pas de chronomètre, mais la partie est assez courte pour qu'on ne ressente pas le besoin d'en avoir un.

"Puis-je voir le code secret ?"
Non, pas à l'écran — mais oui, techniquement, si vous ouvrez la console du navigateur (F12 → Console) et que vous tapez secretCode, vous verrez le tableau des cinq chiffres. C'est un jeu de devinette en JavaScript, il n'y a pas de chiffrement, et c'est très bien comme ça. La triche est possible, mais elle enlève tout l'intérêt, donc personne ne le fait.

"Le thème est-il sauvegardé ?"
Non. Chaque visite commence en Noir. C'est un choix délibéré — l'app est faite pour être ouverte, jouée, refermée sans laisser de trace. Si vous voulez un thème par défaut, ouvrez le fichier dans un éditeur et changez data-theme="noir" sur la balise <body>.

"Ma partie est-elle sauvegardée si je ferme la page ?"
Non. Ni la grille, ni le code, ni vos essais précédents ne sont conservés. À la réouverture, un nouveau code est tiré et vous repartez de zéro. C'est un jeu, pas un dossier.

"Est-ce que ça marche hors ligne ?"
Presque. Le fichier HTML s'ouvre hors ligne, tout le jeu fonctionne, mais les polices Google Fonts (Bangers, Lilita One, Special Elite, Rye) sont chargées depuis un CDN. La première fois, sans réseau, vous verrez les polices système à la place. Une fois chargées avec du réseau, elles sont mises en cache et tout fonctionne hors ligne.

"Puis-je jouer en mode difficile ?"
Non, il n'y a qu'un seul mode. Toutes les parties ont cinq essais, cinq chiffres, et les mêmes couleurs. Si vous voulez compliquer, jouez sans regarder les couleurs du clavier — c'est déjà beaucoup plus dur.

"Puis-je ajouter un mode à six chiffres ou à sept essais ?"
Oui, en modifiant le code. Cherchez const ROWS = 5; et const COLS = 5; en haut du script, et changez les valeurs. La grille se redimensionne automatiquement — mais il faudra aussi ajuster le clavier si vous voulez des chiffres supplémentaires, et le pavé numérique actuel ne contient que 0 à 9.

"Pourquoi le clavier visuel n'affiche-t-il que les chiffres, pas les lettres ?"
Parce que c'est un jeu de chiffres, pas de mots. La version lettre existe, elle s'appelle Wordle et il y en a des dizaines. NUMBRLE88 est une variante strictement numérique — cinq positions, dix symboles possibles, et un retour de couleur identique. Le fait de limiter les symboles change complètement la façon de raisonner.

"Puis-je changer les couleurs d'un thème ?"
Oui, dans le CSS. Chaque thème est un bloc [data-theme="xxx"] qui définit des variables — couleurs de fond, de tuiles, de boutons, polices. Copiez un bloc, renommez-le, ajustez les valeurs. Ajoutez ensuite un bouton correspondant dans l'en-tête et une règle .theme-btn.xxx pour sa couleur. Il n'y a pas de compteur à mettre à jour.

"Le jeu a-t-il un jour donné une mauvaise réponse ?"
Non. La fonction evaluateGuess est écrite selon la logique standard : d'abord tous les verts sont marqués et retirés du pool, puis parmi les chiffres restants, ceux qui apparaissent dans le code sont marqués en jaune. C'est la même logique que Wordle, et elle donne les mêmes résultats pour les mêmes entrées.

"Y a-t-il une limite au nombre de parties ?"
Non. Le bouton New Game est toujours disponible, la modale propose toujours Play Again. Vous pouvez enchaîner autant de parties que vous voulez.
