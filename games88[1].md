## 👋 Bienvenue

Games88 est une page qui rassemble plusieurs jeux. Chaque jeu est un fichier HTML indépendant. La page d'accueil affiche une affiche par jeu. Cliquez sur une affiche pour ouvrir le jeu.

---

## ✨ Ce que vous trouverez

**Six jeux.**  
Card Flip, Rock Paper Scissors, Hangman, Numbrle, Simon Says, Sudoku.

**Affichage en posters.**  
Chaque jeu a une affiche avec un titre, une icône et une catégorie.

**Catégories.**  
memory, reflex, word, numbers, sequence, logic. Chaque catégorie a sa couleur.

**Aucune dépendance.**  
Pas de framework, pas de build, pas de serveur.

**Ajout facile.**  
Copiez un bloc poster dans `index.html` et changez le lien, le titre, l'icône.

---

## 🧭 Comment ça marche

**1. Ouvrez index.html.**  
La page d'accueil s'affiche.

**2. Cliquez sur une affiche.**  
Le jeu s'ouvre dans le même onglet.

**3. Revenez.**  
Utilisez le bouton retour du navigateur.

**4. Ajoutez un jeu.**  
Copiez un bloc poster existant et modifiez-le.

C'est tout.

---

## 🛠️ Petits coups de main

**Où sont les jeux ?**  
Chaque jeu est un fichier HTML dans le même dossier que `index.html`.

**Comment ajouter un jeu ?**  
Ouvrez `index.html`, copiez un bloc `<a class="poster">`, changez le `href` et le titre.

**Quelles catégories existent ?**  
memory, reflex, word, numbers, sequence, logic. Elles définissent la couleur de l'affiche.

**Est-ce que ça marche hors ligne ?**  
Oui, si les fichiers des jeux sont dans le même dossier.

## 👋 Welcome

Games88 is a page that gathers several games. Each game is an independent HTML file. The hub page shows one poster per game. Click a poster to open the game.

---

## ✨ What you'll find

**Six games.**  
Card Flip, Rock Paper Scissors, Hangman, Numbrle, Simon Says, Sudoku.

**Poster layout.**  
Each game has a poster with a title, an icon and a category.

**Categories.**  
memory, reflex, word, numbers, sequence, logic. Each category has its color.

**No dependencies.**  
No framework, no build step, no server.

**Easy to extend.**  
Copy a poster block in `index.html` and change the link, title and icon.

---

## 🧭 How it works

**1. Open index.html.**  
The hub page shows.

**2. Click a poster.**  
The game opens in the same tab.

**3. Go back.**  
Use the browser's back button.

**4. Add a game.**  
Copy an existing poster block and edit it.

That's it.

---

## 🛠️ A little help

**Where are the games?**  
Each game is an HTML file in the same folder as `index.html`.

**How do I add a game?**  
Open `index.html`, copy an `<a class="poster">` block, change the `href` and the title.

**Which categories exist?**  
memory, reflex, word, numbers, sequence, logic. They set the poster color.

**Does it work offline?**  
Yes, if the game files are in the same folder.
